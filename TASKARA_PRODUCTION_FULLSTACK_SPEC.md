# TASKARA — Production Fullstack Blueprint

> Platform micro-job khusus mahasiswa, fresh graduate, UMKM, organisasi kampus, dan bisnis lokal.  
> Dokumen ini menjadi acuan utama untuk product design, UI/UX, frontend, backend, database, keamanan, deployment, dan pengembangan berkelanjutan.

---

## 1. Identitas Produk

### 1.1 Nama Produk

**Taskara**

### 1.2 Tagline

**Dari kemampuan menjadi penghasilan.**

### 1.3 Deskripsi Singkat

Taskara adalah platform marketplace micro-job yang menghubungkan mahasiswa dan talenta muda dengan UMKM, organisasi kampus, startup, komunitas, serta individu yang membutuhkan bantuan untuk menyelesaikan pekerjaan digital maupun operasional.

Contoh pekerjaan:

- Pembuatan landing page
- Pembuatan website profil usaha
- Desain logo dan identitas visual
- Desain poster dan konten media sosial
- Editing video TikTok, Reels, dan YouTube
- Penulisan artikel dan copywriting
- Pengelolaan media sosial
- Entry data
- Pembuatan presentasi
- Dokumentasi acara
- Penerjemahan
- Bantuan tugas teknis
- Pembuatan aplikasi sederhana
- Pengujian website dan aplikasi
- Konsultasi teknologi dasar

### 1.4 Sasaran Utama

#### Pencari Kerja

- Mahasiswa aktif
- Fresh graduate
- Pelajar tingkat akhir
- Freelancer pemula
- Talenta muda yang ingin membangun portofolio
- Tim lintas jurusan

#### Pemberi Kerja

- UMKM
- Organisasi kampus
- Komunitas
- Startup tahap awal
- Pemilik usaha lokal
- Individu
- Lembaga pendidikan
- Penyelenggara acara

## 2. Tujuan Produk

### 2.1 Tujuan Bisnis

1. Membantu mahasiswa mendapatkan penghasilan dari keterampilan yang dimiliki.
2. Membantu UMKM memperoleh jasa digital berkualitas dengan harga terjangkau.
3. Menjadi jembatan antara pendidikan, portofolio, pengalaman kerja, dan penghasilan.
4. Menghasilkan pendapatan melalui biaya platform, paket premium, dan layanan tambahan.
5. Menjadi marketplace micro-job yang kuat di lingkungan kampus dan kota-kota berkembang.

### 2.2 Tujuan Pengguna

#### Freelancer

- Mendapatkan pekerjaan pertama.
- Membangun portofolio terverifikasi.
- Meningkatkan reputasi dan rating.
- Mendapatkan pengalaman proyek nyata.
- Berkolaborasi dengan talenta lain.
- Menerima pembayaran secara aman.

#### Klien

- Menemukan talenta dengan cepat.
- Mendapatkan harga yang transparan.
- Membuat brief pekerjaan dengan mudah.
- Memantau pekerjaan dalam satu dashboard.
- Mengurangi risiko proyek tidak selesai.
- Mendapatkan hasil sesuai kebutuhan.

## 3. Prinsip Produk

Taskara harus dibangun dengan prinsip berikut:

1. **Mudah digunakan oleh pemula**
2. **Transparan dalam harga dan proses**
3. **Aman untuk transaksi**
4. **Berorientasi pada hasil**
5. **Memiliki sistem reputasi yang adil**
6. **Tidak terasa seperti template AI generik**
7. **Tampilan profesional tetapi tetap ramah**
8. **Mendukung perangkat mobile sebagai prioritas**
9. **Memiliki performa cepat**
10. **Siap dikembangkan menjadi skala nasional**

## 4. Model Bisnis

### 4.1 Biaya Platform

Taskara mengambil biaya layanan dari setiap transaksi berhasil.

Contoh:

- Proyek Rp100.000–Rp499.999: biaya 10%
- Proyek Rp500.000–Rp1.999.999: biaya 8%
- Proyek di atas Rp2.000.000: biaya 6%

Besaran biaya dapat dibuat dinamis melalui admin panel.

### 4.2 Posting Prioritas

Klien dapat membayar agar proyek:

- Muncul di posisi teratas
- Mendapat label prioritas
- Mendapat distribusi notifikasi lebih luas
- Direkomendasikan kepada freelancer relevan

### 4.3 Taskara Pro untuk Klien

Fitur:

- Posting pekerjaan lebih banyak
- Pencarian freelancer lanjutan
- Akses template brief premium
- Manajemen tim
- Statistik rekrutmen
- Prioritas dukungan

### 4.4 Taskara Pro untuk Freelancer

Fitur:

- Badge premium
- Portofolio lebih banyak
- Insight performa
- Profil diprioritaskan
- Akses proyek eksklusif
- Sertifikat proyek
- Analitik penawaran

### 4.5 Layanan Tambahan

- Domain
- Hosting
- Maintenance website
- Audit UI/UX
- Konsultasi teknologi
- Pembuatan identitas merek
- Pendampingan UMKM
- Pengelolaan media sosial

- Cerah
- Bersih
- Modern

## 8.3 Rasio Penggunaan Warna

- 70% soft white
- 20% neutral surface
- 8% soft purple
- 2% status colors

Purple harus digunakan untuk:

- Primary button
- Link aktif
- Tab aktif
- Badge utama
- Highlight
- Icon penting
- Focus ring

Purple tidak boleh memenuhi seluruh halaman.

## 8.4 Tipografi

Rekomendasi:

- Heading: **Plus Jakarta Sans**
- Body: **Inter**
- Alternatif: **Geist**

Ukuran:

```css
--font-xs: 12px;
--font-sm: 14px;
--font-base: 16px;
--font-lg: 18px;
--font-xl: 20px;
--font-2xl: 24px;
--font-3xl: 30px;
--font-4xl: 38px;
--font-5xl: 48px;
--font-6xl: 60px;
```

Aturan:

- Body minimal 16px.
- Line-height body minimal 1.6.
- Hindari heading terlalu besar.
- Gunakan maksimal tiga ketebalan font dalam satu halaman.
- Jangan terlalu banyak teks uppercase.

## 8.5 Border Radius

```css
--radius-sm: 8px;
--radius-md: 12px;
--radius-lg: 16px;
--radius-xl: 20px;

```

Aturan:

- Input: 12px
- Button: 12px
- Card: 16px
- Modal: 20px
- Badge: pill
- Jangan semua komponen dibuat terlalu bulat

## 13. Row Level Security

RLS wajib diaktifkan pada tabel sensitif.

Prinsip:

- Profil publik hanya menampilkan data aman.
- Freelancer hanya dapat mengubah profil miliknya.
- Klien hanya dapat mengubah proyek miliknya.
- Proposal hanya dapat dilihat oleh freelancer terkait dan pemilik proyek.
- Percakapan hanya dapat dibaca anggota.
- Wallet hanya dapat dilihat pemilik.
- Admin menggunakan role terpisah dan server-side checks.
- Service role tidak boleh digunakan di client.

Contoh:

```sql
alter table profiles enable row level security;

create policy "public profiles are readable"
on profiles for select
using (is_active = true);

create policy "users can update own profile"
on profiles for update
using (auth.uid() = id)
with check (auth.uid() = id);
```

## 17. Payment Flow

### 17.1 Create Payment

1. Server menerima permintaan.
2. Server memverifikasi proyek dan nominal.
3. Server membuat transaction pending.
4. Server meminta payment token ke provider.
5. Client diarahkan ke payment page.
6. Provider mengirim webhook.
7. Server memverifikasi signature.
8. Transaction diubah menjadi paid.
9. Contract diaktifkan.
10. Dana dicatat sebagai held.

### 17.2 Release Fund

1. Klien menyetujui milestone.
2. Server memeriksa status.
3. Platform fee dihitung.
4. Wallet freelancer ditambahkan.
5. Ledger dibuat.
6. Milestone menjadi released.
7. Notifikasi dikirim.
8. Audit log dibuat.

Gunakan database transaction agar tidak terjadi saldo ganda.
